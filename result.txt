

PERFORMANCE TEST RESULTS (BASELINE - WITHOUT CACHING)


Test Date: 2025-09-05

This report summarizes the performance of the vehicle detection system's
primary API endpoint (GET /api/vehicles) before the implementation of
a Redis caching layer.

The test was conducted using K6, simulating a load ramping up to
100 concurrent virtual users over 2 minutes.

Analysis:
The system demonstrated exceptional reliability with a 100% success rate under significant stress. The throughput is very respectable
for a local development environment. The p(95) latency indicates that the primary bottleneck under heavy load is the repeated calls
to the external MongoDB database, which is the expected behavior for an uncached system.

This data serves as a strong baseline to measure the impact of our
upcoming Redis caching implementation.
